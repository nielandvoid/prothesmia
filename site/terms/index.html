terms

prothesmia is a free countdown tool: a discord bot and a reddit app. using either means you agree to this. it's short.

what it is

it posts countdown cards to a discord channel or a subreddit you choose. it's a hobby project, made and run by one person (niel).

using it

  • use it for countdowns. don't use it to break discord's or reddit's terms, or the law.
  • whoever adds it to a server or a subreddit is responsible for what its countdowns say there. labels, tags and image urls are yours.
  • i can remove a countdown, or block a server or subreddit, if it's being abused.

no promises

it runs on free hosting and is provided as is. it can be slow, restart, change or stop at any time, without notice. a card can show the wrong time if something breaks. don't rely on it as your only reminder for an exam or a deadline - check the official date.

i'm not liable for anything that happens because a card was late, wrong or missing.

changes

these terms or the tools may change. changes go on this page, with the date below. using it after a change means you accept it.
