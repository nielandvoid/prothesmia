setup

invite the bot to your server

in the channel you want, use /countdown set to set a countdown with your desired config

leave it. the embed edits itself on the set interval

commands

  • /countdown setpost or replace a countdown in this channel
  • /countdown configurechange settings on one that already exists
  • /countdown listshow every countdown in the server, with its timers
  • /countdown removedelete a countdown and its card

config

  • labelthe title, for example JEE Main 2027
  • datewritten like 2027-01-04 09:00
  • timezonean IANA name such as Asia/Kolkata; defaults to UTC
  • startwhen the countdown is set, before the set date; optional
  • tagsmall text in the top corner, none to hide
  • fieldsbeside the ring: target, timeLeft, elapsed, or none for nothing
  • thumbnailan image url for the top-right corner / thumbnail of the embed
  • dimensionstall by default, or compact
  • ringdefault / pride / trans
  • intervalhours between updates, 1 to 24; defaults to 1
  • schedulenow / start / custom
  • post_atthe post time for a custom schedule; before the date
  • bumpon or off; a short message that deletes itself after 5 seconds, to wake the channel
  • bump-intervalhours between bumps, 1 to 168; defaults to 24

notes

commands require manage server permission.
the invite requests:
- view channels
- send messages
- embed links
- attach files
- read message history
the channel can stay read-only. the bot only needs to post in it.
several countdowns can share a channel.
uses no privileged intents.

reddit

almost similar to the discord card visually. any mod with everything privileges can add it to their community.

in the subreddit's mod menu, select create countdown post

self-pins in the first slot. set custom config through community's installed apps' settings: developers.reddit.com/r/community/apps/prothesmia - post updates accordingly.

reddit settings

  • eventswritten like name | event date | countdown start, separated by ;; the start is optional
  • timezonean IANA name such as Asia/Kolkata
  • ring styledefault / pride / trans
  • card sizetall by default, or compact; desktop is for wide screens
  • fieldsbeside the ring: target, time left, elapsed, or deselect all for just the ring
  • tagsmall text in the top corner, none to hide
  • live clockdays, hours, minutes and seconds under a smaller ring
  • countdown post titleused when a mod creates the post
  • scheduled threadan optional thread at a set hour, with the days left in the title
