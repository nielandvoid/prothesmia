privacy

prothesmia keeps only what it needs to show a countdown. no accounts, no ads, no tracking, nothing sold.

discord bot

for each countdown you set, it stores:

  • the server id and channel id
  • the label, date, optional start date, tag and timezone
  • the fields, card size, ring style, update-interval and post-schedule
  • an image url, if you set a thumbnail
  • when the card was last refreshed

it only receives the slash commands people use. it can't read messages or member lists, and uses no privileged intents. the data sits in a database hosted on turso, and the bot runs on render. error logs there can include a server id.

if you set a thumbnail, discord fetches that image url and serves it through its own proxy.

reddit app

the settings you give it (events, timezone, ring style and so on) are read from the community's app settings. it keeps two small values in reddit's own app storage: the date of the last scheduled thread, and that thread's post id. it posts and pins as its own account.

it doesn't store anything about the people who view or comment on its posts.

this website

no cookies, no analytics. the fonts load from google fonts, so google can see your ip address when a page loads.

removing your data

on discord, /countdown remove deletes a countdown and its card. to have everything for a server deleted, ask me. on reddit, uninstalling the app stops all posting.
